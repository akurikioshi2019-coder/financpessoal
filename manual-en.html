🚀 Introduction

FinançPessoal is a complete web application for personal financial management, designed to be 100% offline and work directly in your browser. All data is stored locally on your device.

💡 Key Features:
✅ 100% offline - no internet required
✅ Data saved in browser localStorage
✅ Responsive - works on PC, tablet and mobile
✅ Customizable themes (Man/Woman)
✅ Customizable logo (JPEG upload)
✅ PDF reports with charts
✅ 13 integrated modules

📥 Installation

FinançPessoal is a web application that requires no installation. Just open the HTML file in your browser.

📋 Getting Started

1Open the index.html file in your browser
2Use the initial credentials: admin / pass1234
3Change credentials on first use in M11 - Settings
4Start recording your data!
⚠️ Warning: The initial credentials admin / pass1234 are public. Change them immediately after the first login.
💡 Tip: FinançPessoal works in any modern browser: Chrome, Firefox, Safari, Edge, Opera.

On the login screen, click "👤 Admins" to:

💡 Tip: After the first login, you must change the credentials. Go to M11 - Settings to change name and password.

💰 M2 - Transactions and Categories

Record all your income and expenses simply and quickly.

📋 How to Record a Transaction

1Enter the Amount (e.g., 25.50)
2Select the Type: Income or Expense
3Choose the Category or create a new one
4Add a Description
5Select the Bank Account (M7)
6Check "🔁 Recurring Transaction" if you want to save it
7Click 💾 Save

🔄 Recurring Transactions

  • Mark as Recurring: Check the box before saving
  • Use Recurring: Click "📋 Use" to fill the form
  • Edit Recurring: Click "✏️" to edit amount, description or type
  • Remove Recurring: Click "🗑️" to delete
  • Edit Transaction: Click "✏️" in the recent transactions list
  • Delete Transaction: Click "🗑️" in the recent transactions list
💡 Tip: Use the "Recurring Transaction" option for recurring expenses like utility bills, rent, internet, etc.
✅ Integration: Transactions in special categories (M5, M6, M10) require confirmation from the source module.
